# Store screenshots — automatic generation

The store screenshots (Google Play, F-Droid) and the *feature graphic* banner are generated by a
Robolectric test, with no emulator or device, straight into
`fastlane/metadata/android/<locale>/images/`:

```bash
./gradlew :app:testDebugUnitTest -PstoreScreenshots
```

Without `-PstoreScreenshots`, this test is excluded from `./gradlew test`: it is slow (a few
minutes) and rewrites the files in `fastlane/`.

## What gets generated

| File | Size |
|---|---|
| `phoneScreenshots/1.png` … `7.png` | 1080 × 2160 |
| `sevenInchScreenshots/1.png` … `7.png` | 1200 × 1920 |
| `tenInchScreenshots/1.png` … `7.png` | 1600 × 2560 |
| `featureGraphic.png` | 1024 × 500 |

For `fr-FR` and `en-US`, 44 images in total. All of them respect Google Play's 2:1 aspect ratio
limit.

## Design

The style follows the website (`cairngps-website`): alternating forest `#0d3b30` and cream
`#f3ebdd` backgrounds, Fraunces headlines whose ending is in italics (peach on forest, clay on
cream), a numbered Roboto Mono eyebrow, the contour lines from the home page hero, and phones
cropped at the bottom of the image. Tablets show a single, larger device.

The screens are the **real app screens** (`MainScaffold`), fed with the same fake data as the
guided tour and demo mode (`demo/`), with the clock frozen at a fixed instant: position, sky and
heading are identical from one run to the next. The status bar is drawn (12:00, full battery, no
notifications).

## Where to change what

Everything lives in `app/src/test/java/app/matthieu/cairngps/storescreenshots/`:

- `StoreCopy.kt` — the taglines, eyebrows and figures, in French and English. The figures
  (6 constellations, 66 achievements) must stay accurate and consistent with the website.
- `StoreScreenshotsTest.kt` — the order of the screenshots, the screen shown in each one, its
  theme (light or dark), the background and the position of the contour lines.
- `StoreFrame.kt` — the layout: frame, typography, device, status bar, banner.
- `StoreContainer.kt` — the fake data; the spoofing alert in screenshot 6 comes from a one-hour
  offset between the simulated GNSS time and network time.

The Fraunces and Manrope fonts (`app/src/test/resources/store-fonts/`, OFL license) are only used
by the generator and are not shipped in the APK.

## Publishing

- **F-Droid** reads `fastlane/metadata/android/` from the repository: the new images show up with
  the next tagged release, nothing to do.
- **Google Play** is updated by the `Play Store listing` workflow
  (`.github/workflows/play-listing.yml`), which runs fastlane `supply` on every push to `main`
  that changes `fastlane/metadata/android/*/images/`. It uploads the screenshots, the feature
  graphic and the icon only, and only those that changed: texts, changelogs and bundles are left
  alone. Changes go live once Google has reviewed them (or once sent for publication from Play
  Console, if managed publishing is on).

It can also be run by hand (Actions → Play Store listing → Run workflow). A manual run is
**validate only** by default: Google checks the changes without publishing anything. Untick it to
publish.

### One-time setup

1. Play Console → **Setup → API access**: link a Google Cloud project, then create a
   **service account** in it and download a JSON key.
2. Play Console → **Users and permissions**: invite the service account's email, with access to
   CairnGPS only and a single permission, **Edit store listing, pricing & distribution**.
3. GitHub → **Settings → Secrets and variables → Actions**: add the JSON key's content as
   `PLAY_SERVICE_ACCOUNT_JSON`.
4. Run the workflow by hand with *validate only* ticked to check the setup.

Until the secret is set, the workflow is skipped with a notice instead of failing. Both `fr-FR`
and `en-US` must exist as languages of the Play listing.
